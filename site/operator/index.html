Scope: organize submitted material into an editable draft, preserve source provenance and uncertainty, then hand the draft to a separately controlled runtime only when an operator chooses to do so.

Prepare a review draft

Paste source text and, optionally, its URL. Public Operator keeps both local and treats the URL as unverified attribution; authenticated private Operator may retrieve the URL through controlled intake. Neither path verifies truth, infers motives, scores risk, or executes the Semantic Engine.

The authenticated private Operator can send this URL to controlled intake. Public Operator does not send it; paste the relevant source text below instead.

On the public Operator, an exact URL supplied with source text stays local as unverified attribution; explicit share actions can include it. On the authenticated private Operator, retrieval sends that exact URL, including its path, query and fragment, to controlled intake. Do not use private or signed links, tokens, one-time passwords or personal data.

Open authenticated URL intake · Automatic retrieval is limited to authorized owner/team accounts. Public Operator continues to support pasted source text without sending the URL.

Automatic classification is conservative. Select an explicit type here when the operator has a more accurate classification.

In the public Operator, pasted text is used in full as the local source; the 1,200-character context limit does not apply. In the authenticated private Operator, when a URL is retrieved, up to 1,200 Unicode characters of pasted text are recorded separately as local operator context. The draft indicates whether any remainder was omitted.

Controlled runtime handoff

        
Generate a copy/paste command for a separately controlled local runtime. The command validates the case JSON, checks local API health, saves the response and verifies the structured analysis-result contract before printing it. Operator does not call `/analyze` or claim that an engine run occurred.
