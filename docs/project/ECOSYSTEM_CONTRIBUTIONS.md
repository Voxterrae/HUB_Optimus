# Creaciones e integraciones en el ecosistema

Related to #2187. Refs #2185 y #1936; las tres incidencias permanecen abiertas.

**Corte de evidencia pública: 14-11-2026, Europe/Madrid**, árbol
`53b7a841e028592ca81fb43d04d15a2b017bbd78`. Es una revisión documental, no una certificación de producción.

El trabajo de HUB_Optimus es más amplio que sus tres aportaciones upstream
comprobadas. El registro separa cuatro relaciones para conservar el crédito real:

| Relación | Qué acredita | Evidencia necesaria |
| --- | --- | --- |
| Creación propia | Método, herramienta, documentación o código del proyecto | Fuente versionada y crédito de sus contribuidores |
| Integración | Trabajo propio para usar una plataforma o API existente | Código/contrato y límites; no implica ser autor de la plataforma |
| Aporte externo enviado | Una propuesta, reporte, validación o PR entregados a otro proyecto | Objeto o recibo de entrega atribuible |
| Aporte aceptado | El destinatario aceptó una contribución concreta | Respuesta o merge aplicables; se registra aparte del envío |

Este corte reúne **24 grupos** de creación o integración. No son 24
productos independientes ni cambios aceptados por OpenAI, Microsoft u otros
proveedores. Las tres contribuciones externas ya verificadas conservan sus
[fuentes y estados propios](CONTRIBUTIONS_REGISTER.md#aportaciones-a-otros-proyectos).

## Referencias externas utilizadas y atribución pendiente

La discusión pública [microsoft/win32metadata #2308](https://github.com/microsoft/win32metadata/discussions/2308)
trata `TokenHasRestrictions` y la discrepancia entre el tamaño documentado y el
observado. Su autor visible es **KRYST4LBEI**; la relación con HUB_Optimus o
Voxterrae no está acreditada por las fuentes públicas inspeccionadas. Se conserva
como referencia técnica utilizada, no como contribución propia ni del fundador.

La propuesta de un piloto, el uso intensivo de una herramienta y el reporte de un
fallo son trabajos distintos. Las propuestas preparadas, comunicaciones privadas
y accesorios restringidos se reconcilian en el contexto interno; este registro
no los convierte en envíos o aceptaciones públicos. No se han publicado sus
URLs, identificadores de acceso, conversaciones, diagnósticos ni datos de clientes.

## Cobertura y siguientes comprobaciones

Se examinaron 1.005 archivos públicos de texto y 2.370 mensajes de commits
existentes entre las refs locales, además de las fuentes agrupadas arriba.
Ese recuento supera el grafo de main: incluye ramas y propuestas que no están
integradas. Cada ficha debe conservar su estado; no sumarlas a productos activos.

La recuperación de contexto conversacional es selectiva, no un acceso íntegro o
exportación de todos los chats. Los documentos y metadatos privados recuperados
sirven para localizar trabajo; no acreditan por sí solos envío al proveedor.

Pendiente: recuperar recibos atribuibles de feedback/propuestas a proveedores,
clasificar aportes de colaboradores con su crédito real y conciliar accesorios
fuera del repositorio. Un resultado de búsqueda vacío no demuestra ausencia.
El [catálogo de capacidades y pilotos](CAPABILITIES_AND_PILOTS.md) indica dónde
hay un siguiente incremento verificable. Ninguna novedad de proveedor se infiere
a partir de que HUB_Optimus haya usado su plataforma.
