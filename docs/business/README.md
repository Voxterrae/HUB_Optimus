The current proposed commercial hierarchy under issue `#1863` is:

2. `PLATFORM_MONETIZATION_AND_PRICE_BOOK_v0.2.md` — current platform, application,

3. `TAX_PROCUREMENT_AND_CLEAN_PAYMENT_POLICY_v0.1.md` — procurement, invoicing,
   tax-information, payment, and clean-funds boundary.

5. `FOUNDER_RND_VALUE_LEDGER_v0.1.md` — founder-funded construction value.
6. `MARKET_BENCHMARK_2026.md` — dated external market evidence and interpretation.
7. `config/business/commercial_policy.v0.2.json` — machine-readable policy.

`config/business/commercial_policy.v0.1.json` are retained only as historical
construction records. They must not be used for new quotations after v0.2 is
ratified.
