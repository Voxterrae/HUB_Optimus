# Backend Architecture

## Python Runtimes

1. [[Scenario Contract and Loader]]
2. [[Round-based Simulator]]
3. [[Semantic Engine Contracts and CLI]]
4. [[Controlled URL Intake]]
5. [[Local HTTP API]]
6. [[Local Control Prototype]] — isolated/experimental

## Shell Orchestration

[[EC2 Core Runner and Run Registry]] wraps runtime commands against a pinned current release. [[EC2 Release Operations]] controls candidate validation, deployment and rollback.

## HTTP Shape

The API is generated by a shell launcher and uses Python stdlib `HTTPServer`. It is synchronous and loopback-only by default.

## Contract-first Boundaries

- JSON Schema Draft 2020-12.
- strict JSON and finite numbers.
- cross-record identity/reference checks.
- exact run identity.
- explicit response/error shapes for intake.

## Persistence

No central database is implemented. Persistence is local files/runs and browser IndexedDB. S3/vector database/enterprise storage remain absent.
