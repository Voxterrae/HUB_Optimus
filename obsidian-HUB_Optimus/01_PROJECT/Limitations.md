# Limitations

## Explicit Non-capabilities

- Autonomous truth adjudication or motive inference
- Prediction or probabilistic forecasting of real-world outcomes
- Full automatic execution of the canonical v1 methodology
- Public authenticated Semantic Engine service
- HERMES production application
- Post-quantum control plane
- Enterprise billing, authentication or customer tenancy
- Proof of current Pages, EC2, DNS, TLS, Nginx or repository-settings state
- AI ownership, self-ratification or autonomous merge authority

## Runtime Limits

### Scenario runtime

- Solo JSON estricto bajo `scenario.schema.json`.
- Políticas simples y criterios de coincidencia exacta.
- Resultados sintéticos, no diplomacia ni forecast.

### Semantic Engine

- Valida estructura y referencias.
- Ensambla registros submitted/draft.
- No evalúa verdad, calidad, personas ni consecuencias.

### Operator

- Local-first y human-reviewed.
- No demuestra backend público, autenticación o sincronización remota.
- Sus drafts y learning candidates no son canónicos.

### Controlled intake

- Una URL, hasta tres redirects, tiempo/tamaño acotados.
- No cookies, auth, browser automation, crawling o paywall bypass.
- `verification_status=unreviewed`.

### Infrastructure

- Los scripts no son infraestructura como código completa.
- El repo no certifica host, DNS, TLS, firewall, NAT, resolver o uptime.

## Evidence Limits

Un test verde prueba únicamente lo que afirma. Un documento versionado prueba que el documento existe. Un workflow fuente prueba el mecanismo definido, no que una ejecución concreta haya terminado correctamente.

## Legal, Scientific and Professional Boundaries

Este repositorio no convierte texto, tests o IA en asesoramiento legal, certificación científica, revisión profesional de traducción o autoridad institucional.
